## 무엇을 하는 앱인가요

저는 평소 MacBook으로 일하면서 원격 데스크톱 앱(UU Remote, Sunlogin, ToDesk 등)으로 Mac mini에 접속해 작업합니다. Claude Code에게 코드를 맡기거나, 영상을 편집하거나, 웹사이트를 관리하는 식입니다.

문제는 **Mac mini에는 마이크가 없고, 원격 데스크톱 앱도 MacBook의 마이크를 넘겨주지 않는다**는 점입니다. 그래서 원격 데스크톱 안에서는 음성 입력을 쓸 수 없습니다.

MicHop은 바로 이 문제를 해결합니다. 두 컴퓨터에 하나씩 설치하세요.

- **말하는 컴퓨터**(예: MacBook): ‘MicHop’ 설치
- **작업하는 컴퓨터**(예: Mac mini): ‘MicHop Receiver’ 설치

```
MacBook(말하는 쪽)                           Mac mini(작업하는 쪽)

마이크 ──── 🔊 소리 ──────────────►  가상 마이크(기본 제공 MicHop Audio)
                                      → 받아쓰기 / WeChat 입력기 / Claude Code 음성 모드

              로컬 네트워크 또는 Tailscale 경유
```

MacBook 마이크의 소리가 실시간으로 Mac mini에 전달되어 Mac mini의 마이크가 됩니다. 시스템 받아쓰기, WeChat 입력기의 음성 입력, Claude Code의 음성 모드 등 Mac mini에서 마이크가 필요한 앱이라면 무엇이든 쓸 수 있습니다.

- 수신기에는 가상 오디오 장치 **MicHop Audio**가 포함되어 있어 따로 내려받을 필요가 없습니다. 처음 열 때 설치하라는 안내가 나오며, 관리자 암호를 한 번 입력하면 됩니다. 예전에 [BlackHole](https://github.com/ExistentialAudio/BlackHole)을 설치했다면 그대로 계속 써도 됩니다.
- 말하는 방법은 두 가지이며 언제든 둘 다 쓸 수 있습니다. **⌃⌥M**을 한 번 누르면 계속 전송하고 다시 누르면 멈춥니다. 또는 **⌃⌥을 누른 채** 말하고 떼면 멈춥니다.
- 에코 제거 기능이 있어 원격 데스크톱 앱으로 연결한 상태에서도 소리가 울리지 않습니다.
- 원격 데스크톱 앱으로는 Fn 키가 전달되지 않습니다. Mac mini에서 음성 입력 단축키를 Ctrl + Option 같은 수정 키 조합으로 바꿔 두세요. [자세한 내용은 아래를 참고하세요](#팁-원격-연결에서는-fn-키가-전달되지-않으니-단축키를-바꾸세요).

### 두 컴퓨터를 연결하는 방법

- **같은 로컬 네트워크에 있을 때**: Mac mini의 LAN IP를 입력하면 됩니다.
- **떨어져 있을 때**: 두 컴퓨터 모두 [Tailscale](https://tailscale.com)을 설치해 가상 네트워크를 만들고, Mac mini의 **Tailscale IP**(100으로 시작)를 입력하세요. 집에서든 밖에서든 똑같이 쓸 수 있습니다.
- 수신기 창에 LAN IP, Tailscale IP, 암호가 표시되며, 항목마다 옆에 복사 버튼이 있습니다.

### 그 밖의 특징

- **클라우드를 전혀 거치지 않습니다**: 소리는 내 컴퓨터 두 대 사이에서만 직접 오가며, 전 구간 암호화된 채로 로컬 네트워크나 Tailscale을 통해 전달됩니다.
- **원격 데스크톱 앱과 무관합니다**: UU Remote, Sunlogin, ToDesk, 화면 공유 어느 것과도 함께 쓸 수 있습니다.
- **자동 업데이트**: 새 버전이 나오면 알아서 업데이트하며, 권한을 다시 허용할 필요가 없습니다.
- **다국어 지원**: 简体中文, 繁體中文, English, 日本語, 한국어, Español, Français, Deutsch, Português, Русский를 지원합니다. 기본값은 중국어이며 ‘설정… → 일반 → 언어 / Language’에서 바꿀 수 있습니다.

## 다운로드 및 설치

[Releases](../../releases/latest)에서 내려받으세요.

| 파일 | 설치할 컴퓨터 | 메뉴 막대 아이콘 |
|---|---|---|
| `MicHop.zip`(MicHop) | 말하는 컴퓨터(예: MacBook) | 앱 아이콘과 같은 마이크 두 개 |
| `MicHop-Receiver.zip`(MicHop Receiver) | 작업하는 컴퓨터(예: Mac mini) | 위와 같음 |

메뉴 막대 아이콘의 색으로 상태를 알 수 있습니다. **회색**은 연결 안 됨, **녹색**은 연결됨, **빨간색**은 음성 전송 중입니다.

> **두 앱 모두 메인 창이 중심입니다**: Dock 아이콘을 클릭하면 메인 창이 열리고, 위쪽 두 칸에 ‘연결 상태’(회색 / 파란색)와 ‘음성’(회색 / 빨간색)이 표시됩니다. 자주 쓰는 기능은 모두 창 안에 있고, 단축키·언어·자동 업데이트 등은 ‘설정…’(⌘,)에 있습니다. 메뉴 막대 아이콘과 Dock 아이콘의 오른쪽 클릭 메뉴에는 가장 자주 쓰는 몇 가지만 남겨 두었습니다. MacBook의 카메라(노치)가 메뉴 막대 아이콘을 가리면 Dock 아이콘을 쓰세요.

macOS 13 이상이 필요하며, Apple 실리콘과 Intel Mac 모두 지원합니다.

> **처음 열 때 ‘개발자를 확인할 수 없음’이라고 나온다면**: 이 앱이 유료 Apple 공증을 받지 않았기 때문입니다. 시스템 설정 → 개인정보 보호 및 보안을 열고 페이지 아래쪽에서 ‘그래도 열기’를 클릭하세요. 또는 터미널에서 다음 명령을 실행해 격리 속성을 없앤 뒤 열어도 됩니다.
> ```bash
> xattr -dr com.apple.quarantine "/Applications/MicHop Receiver.app"
> ```

### 1. 작업하는 컴퓨터(수신기)

1. `MicHop-Receiver.zip`의 압축을 풀고 ‘MicHop Receiver’를 ‘응용 프로그램’ 폴더로 드래그한 뒤 여세요.
   - 들어오는 네트워크 연결을 허용할지 묻는 창이 뜨면 **허용**을 클릭하세요.
2. 처음 열면 기본 제공 가상 오디오 장치 **MicHop Audio**를 설치하라는 안내가 나옵니다. ‘설치’를 클릭하고 관리자 암호를 한 번 입력하세요. 설치하는 동안 시스템 소리가 1~2초 끊깁니다. 나중에 ‘설정… → 가상 오디오 장치’에서 설치해도 됩니다.
3. 설치가 끝나면 안내에 따라 **시스템 입력 장치**를 MicHop Audio로 바꾸세요(메인 창의 ‘준비 상태’에도 ‘바꾸기’ 버튼이 있습니다). 시스템 **출력** 장치는 스피커(또는 원격 데스크톱 앱의 오디오 장치) 그대로 두면 됩니다. MicHop Audio는 시스템 출력으로 선택할 수 없으므로 시스템 소리가 섞여 들어가지 않습니다.
4. 메인 창에서 다음을 볼 수 있습니다.
   - **연결 정보**: 이 Mac의 LAN 주소, Tailscale 주소, 암호. 항목마다 옆에 복사 버튼이 있습니다.
   - **준비 상태**: 가상 오디오 장치와 시스템 입력 장치에 모두 녹색 체크 표시가 있으면 준비된 것입니다. 노란색 경고가 뜬 항목은 오른쪽에 바로 고칠 수 있는 버튼이 표시됩니다.
5. 기본적으로 로그인할 때 자동으로 실행됩니다. 원하지 않으면 ‘설정… → 일반’에서 끄세요.

> **예전에 BlackHole을 설치했나요?** 그대로 쓸 수 있습니다. ‘준비 상태 → 소리 출력 장치’에서 원하는 장치를 고르세요. 기본 제공 장치로 바꾸려면 ‘기본 제공 가상 장치로 바꿀 수 있습니다’ 옆의 ‘설치’를 클릭하세요. BlackHole을 쓸 때는 시스템 출력으로 선택하지 않도록 주의하세요. 잘못 선택하면 ‘준비 상태’에 ‘시스템 출력’ 경고가 나타나는데, ‘스피커로 되돌리기’를 클릭하면 됩니다.

### 2. 말하는 컴퓨터(송신기)

1. `MicHop.zip`의 압축을 풀고 ‘MicHop’을 ‘응용 프로그램’ 폴더로 드래그한 뒤 여세요.
2. 처음 열면 설정 창이 나타납니다. 수신기의 **주소**와 **암호**를 입력하고 ‘연결 테스트’를 클릭하세요. 녹색으로 ‘연결됨 — 바로 쓸 수 있습니다’가 표시되면 ‘저장’을 클릭합니다.
   - 수신기 창에서 주소와 암호 옆의 복사 버튼으로 각 항목을 따로 복사할 수 있습니다.
   - 수신기에서 ‘모두 복사’를 클릭한 뒤 통째로 ‘주소’ 칸에 붙여넣어도 됩니다. 송신기가 주소를 알아서 골라내고(Tailscale 주소가 있으면 우선 사용) 암호도 자동으로 채웁니다.
   - 로컬 네트워크에서 기기를 찾도록 허용할지 묻는 창이 뜨면 **허용**을 클릭하세요.
3. 처음에는 **마이크** 권한을 요청하니 허용하세요. **손쉬운 사용** 권한(‘⌃⌥ 누르고 있기’를 감지하는 데 쓰임)도 요청하는데, 안내에 따라 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → ‘MicHop’을 켜세요.
4. 앱을 열면 수신기에 연결됩니다. 메인 창의 ‘연결 상태’가 파란색으로, 메뉴 막대 아이콘이 녹색으로 바뀌면 쓸 준비가 된 것입니다. 나중에 주소나 암호를 바꾸려면 메인 창 ‘수신기’ 항목의 ‘변경…’을 클릭하거나 ⌘,를 누르세요.

## 사용 방법

먼저 원격 데스크톱에서 작업하는 컴퓨터의 음성 입력을 쓸 곳(예: Claude Code 음성 모드, 시스템 받아쓰기, 입력기)을 클릭하세요. 그다음 두 가지 방법 중 원하는 쪽으로 언제든 말하면 됩니다.

1. **계속 전송**: **⌃⌥M(Ctrl + Option + M)** 키를 한 번 누르거나 메인 창의 ‘음성 전송 시작’을 클릭하면 마이크가 계속 켜져 있습니다. 다시 누르면 멈춥니다.
2. **누르는 동안 전송**: **Ctrl + Option을 누른 채 말하고, 떼면 멈춥니다**. 누르고 있는 동안에만 마이크가 켜집니다.

전송 중에는 메인 창의 ‘음성’과 메뉴 막대 아이콘이 빨간색으로 바뀌고, 수신기 쪽의 ‘음성’도 빨간색이 됩니다.

- 누르고 있는 키 조합은 원격 데스크톱 앱을 통해 작업하는 컴퓨터에도 전달됩니다. 그 컴퓨터에서 받아쓰기나 입력기의 음성 단축키도 Ctrl + Option으로 설정해 두면([아래 팁 참고](#팁-원격-연결에서는-fn-키가-전달되지-않으니-단축키를-바꾸세요)) **한 번 누르는 것만으로 ‘음성 전송’과 ‘저쪽에서 받아쓰기 시작’이 동시에 됩니다**.
- 누른 채 말하는 동안 MicHop은 이 Mac의 소리를 잠시 음소거합니다. 상대 컴퓨터의 소리가 원격 데스크톱 앱을 통해 되돌아와 마이크에 다시 들어가면서 에코가 생기는 것을 막기 위해서입니다. 키를 떼고 약 1초 뒤 자동으로 돌아옵니다. (‘계속 전송’에는 Apple의 에코 제거를 씁니다.)

> **단축키는 바꿀 수 있습니다**: ‘설정… → 단축키’에서 버튼을 클릭한 다음 새 키 조합을 누르세요. ‘전송 시작’에는 ⌃, ⌥, ⌘ 중 하나가 들어간 조합이면 무엇이든 쓸 수 있고, ‘눌러서 말하기’에는 ⌃ ⌥ ⇧ ⌘ 중 두 개 이상을 조합해야 합니다. 고른 조합을 시스템이 이미 쓰고 있다면(예: 많은 Mac에서 ⌃⌥Space는 ‘입력 메뉴에서 다음 소스 선택’입니다) 앱에 주황색 안내가 표시됩니다. 시스템 설정 → 키보드 → 키보드 단축키에서 그 항목을 끄거나 다른 조합을 고르세요.

> **왜 에코가 생기나요?** 많은 원격 데스크톱 앱(예: UU Remote)은 Apple의 화면 녹화 프레임워크로 원격 컴퓨터의 소리를 수집하는데, 이때 어느 오디오 장치로 재생되는지와 상관없이 그 컴퓨터에서 **모든 앱이 내는 소리**를 녹음합니다. MicHop이 내 목소리를 가상 오디오 장치로 재생하면 그 소리도 함께 녹음되어 내 컴퓨터로 돌아오고, 스피커로 나온 뒤 다시 마이크에 들어갑니다.
>
> 그래서 송신기는 기본적으로 **에코 제거**를 켜 둡니다(메인 창의 ‘옵션’에서 끌 수 있습니다). FaceTime에도 쓰이는 Apple의 음성 처리 기술로, 되돌아온 소리를 마이크 입력에서 빼고, 말하는 동안 다른 소리를 줄이며, 소음도 함께 줄여 줍니다. 헤드폰을 쓰면 효과가 가장 좋습니다.

### 팁: 원격 연결에서는 Fn 키가 전달되지 않으니 단축키를 바꾸세요

UU Remote, Sunlogin, ToDesk 같은 원격 데스크톱 앱으로 연결했을 때 **이 Mac에서 Fn 키를 눌러도 원격 컴퓨터에는 전달되지 않습니다**. 원격 컴퓨터에서 시스템 받아쓰기를 쓰든 WeChat 입력기의 음성 입력을 쓰든 실행되지 않습니다. 이유는 두 가지입니다. Fn 키는 이 Mac이 먼저 가로채고(이 Mac에서 받아쓰기가 시작됨), 설령 원격 데스크톱 앱이 전달하더라도 원격 컴퓨터에서는 ‘가상 키 입력’일 뿐이라 시스템과 입력기가 대개 인식하지 않습니다.

해결 방법: **원격 컴퓨터**(예: Mac mini)에서 음성 입력 단축키를 바꾸세요.

- **시스템 받아쓰기**: 시스템 설정 → 키보드 → 받아쓰기 → 단축키 → ‘사용자화’.
- **WeChat 입력기**: WeChat 입력기 설정에서 음성 입력 단축키를 바꾸세요.

**수정 키 조합**을 권장합니다. 예를 들어 **왼쪽 Ctrl + Option**, 또는 Ctrl과 다른 수정 키(Option, Shift, Command)의 조합입니다.

**Ctrl + 숫자 키나 Ctrl + 문자 키(예: Ctrl+D)는 피하세요.** 음성 입력은 보통 키를 누른 채 말해야 하는데, 문자나 숫자 키를 누르고 있으면 그 문자가 계속 반복 입력되어 무척 불편합니다. 수정 키만으로 된 조합은 누르고 있어도 문자가 입력되지 않습니다.

원격 컴퓨터의 입력 장치를 MicHop Audio로 설정하고, 원격 데스크톱에서 새 단축키를 누른 채 말하면 원격 컴퓨터에서 바로 받아쓰기가 됩니다.

## Mac mini의 소리를 돌려받기(가상 스피커)

수신기에 기본 제공되는 가상 오디오 장치에는 **가상 스피커 MicHop Speaker**도 들어 있습니다(1.6.0부터). 내 마이크 소리를 재생하는 MicHop Audio와는 서로 독립된 장치라서 소리가 섞이지 않습니다.

수신기의 ‘설정… → 가상 오디오 장치’에서 ‘이 Mac의 소리를 MicHop Speaker로 보내기’를 켜면:

- Mac mini의 시스템 출력이 MicHop Speaker로 바뀌어 **이 Mac의 스피커에서는 소리가 나지 않습니다**. 방 안에서 갑자기 소리가 울릴 일이 없습니다.
- 오디오 장치를 골라야 하는 원격 데스크톱 앱이나 화면 녹화 앱(예: Sunlogin, 일부 버전의 ToDesk, OBS)에서는 MicHop Speaker를 소리 출처로 골라 Mac mini의 소리를 돌려받을 수 있습니다.
- 키보드의 음량 키도 그대로 쓸 수 있고, 녹음되는 소리도 음량에 따라 달라집니다.
- 스위치를 끄거나, 수신기를 종료하거나, 가상 오디오 장치를 제거하면 시스템 출력은 자동으로 원래 장치로 돌아갑니다.

> UU Remote처럼 Apple의 화면 녹화로 소리를 수집하는 원격 데스크톱 앱은 소리가 어느 장치로 재생되든 녹음할 수 있습니다. 그래서 이런 앱에서 가상 스피커의 가장 큰 장점은 ‘Mac mini의 스피커는 조용하고, 원격 쪽에서는 그대로 들린다’는 점입니다.

수신기 메인 창 ‘준비 상태’의 마지막 줄 ‘이 Mac의 소리’에서 이 컴퓨터의 소리가 지금 어디로 가고 있는지 볼 수 있습니다.

## 같은 네트워크가 아닌가요? Tailscale을 쓰세요

1. 두 컴퓨터 모두 [Tailscale](https://tailscale.com)을 설치하고 같은 계정으로 로그인하세요.
2. 수신기 메인 창 ‘연결 정보’의 ‘Tailscale’ 줄에 100.x.x.x가 표시됩니다. 이 주소를 송신기 설정에 입력하세요. Tailscale에 표시되는 기기 이름을 입력해도 됩니다.
3. ‘찾지 못함’이 표시되면 먼저 수신기 컴퓨터의 Tailscale이 연결되어 있는지 확인한 다음, 그 줄의 새로고침 버튼을 클릭해 다시 감지하세요. 그래도 감지되지 않으면 수신기의 ‘설정… → Tailscale → 주소 직접 입력’에 Tailscale 메뉴에 표시된 주소를 입력하세요.

Tailscale 주소는 집에서든 밖에서든 쓸 수 있으며, 같은 로컬 네트워크에 있을 때는 자동으로 직접 연결됩니다.

## 보안

- **소리는 전 구간 암호화됩니다**: 연결할 때마다 먼저 키 교환(X25519)을 하고, 그 뒤 모든 소리 조각을 ChaCha20-Poly1305로 암호화합니다. 같은 네트워크에서 엿듣거나 패킷을 가로채는 사람은 내가 하는 말을 들을 수 없고, 암호도 알아낼 수 없습니다. 암호 자체는 네트워크로 절대 전송되지 않습니다.
- 수신기마다 무작위로 만든 6자리 암호가 있으며, 암호가 틀린 연결은 모두 거부합니다. 5번 연속 틀리면 수신기는 30초 동안 새 연결을 받지 않고, 메인 창에 ‘누군가 암호를 시도하고 있습니다’라는 알림이 뜹니다. 수신기 메인 창의 ‘암호’ 줄에서 ‘새로 만들기’를 클릭하면 바꿀 수 있습니다(바꾼 뒤에는 송신기에서 다시 입력해야 합니다).
- **막을 수 없는 경우**: 연결을 능동적으로 가로채 수신기로 위장하는 사람. 6자리 암호는 경우의 수가 100만 가지뿐이라, 핸드셰이크를 한 번 손에 넣으면 오프라인에서 맞혀 볼 수 있습니다. 그러니 가정용 네트워크나 Tailscale 안에서만 쓰고, 수신기의 포트(TCP **8766**)를 인터넷에 노출하지 마세요.
- 송신기와 수신기 모두 1.6.0 이상이어야 합니다. 한쪽이 너무 오래된 버전이면 다른 쪽에서 버전이 너무 오래됐으니 업데이트하라고 안내합니다.

## 자주 묻는 질문

- **연결되지 않습니다**: 두 컴퓨터가 같은 네트워크에 있는지, 또는 둘 다 Tailscale에 연결되어 있는지 확인하세요. LAN IP는 바뀔 수 있으므로 공유기에서 수신기에 고정 IP를 지정하거나 Tailscale 주소를 쓰는 것이 좋습니다.
- **수신기에 포트를 열 수 없다고 나옵니다**: 보통 예전 수신기가 완전히 종료되지 않고 포트를 잡고 있는 경우이며, 수신기가 자동으로 그 프로세스를 종료합니다. 다른 앱이 포트를 쓰고 있다면 안내에 그 앱 이름이 표시되고, 포트가 풀리면 수신기가 자동으로 시작됩니다.
- **⌃⌥을 눌러도 반응이 없습니다**: 송신기에는 **손쉬운 사용** 권한이 필요합니다. 앱을 다시 빌드하거나 업데이트하면 macOS가 기존 권한을 무효로 만들 때가 있습니다. 손쉬운 사용 목록에서 예전 항목을 먼저 삭제한 뒤 다시 추가하세요.

## 자동 업데이트

두 앱 모두 GitHub에서 새 버전을 스스로 확인합니다. 실행 30초 뒤 한 번 확인하고, 이후 6시간마다 확인합니다. 새 버전을 찾으면 자동으로 내려받아 교체한 뒤 다시 엽니다.

- 메인 창 왼쪽 아래에서 현재 버전을 볼 수 있습니다. ‘설정… → 일반’에서 ‘업데이트 확인’을 클릭하면 바로 확인합니다.
- 자동 설치를 원하지 않으면 ‘설정… → 일반’에서 ‘자동으로 업데이트 설치’를 끄세요. 그러면 새 버전이 나왔을 때 설정에 ‘x.y.z(으)로 업데이트’ 버튼이, 메뉴 막대 메뉴에도 같은 항목이 나타나고, 직접 클릭해야 업데이트됩니다.
- 사용 중에는 방해하지 않습니다. 음성을 전송하는 동안에는 업데이트하지 않습니다.
- 보안: 새 버전은 현재 버전과 **같은 인증서**로 서명되어 있어야 하며, 그렇지 않으면 설치를 거부합니다.
- 업데이트 후에도 손쉬운 사용, 마이크 등의 권한이 유지되므로 다시 허용할 필요가 없습니다.
