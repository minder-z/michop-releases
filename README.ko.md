## 무엇을 위한 앱인가요

저는 평소 MacBook으로 일하면서, 원격 데스크톱 소프트웨어(UU Remote, Sunlogin, ToDesk 등)로 Mac mini에 접속해 작업합니다. 예를 들어 Claude Code에게 코드를 작성하게 하거나, 영상을 편집하거나, 웹사이트를 관리하죠.

문제는 **Mac mini에는 마이크가 없고, 원격 데스크톱 소프트웨어도 MacBook의 마이크를 넘겨주지 않는다**는 점입니다. 그래서 원격 데스크톱 안에서는 음성 입력을 할 수 없습니다.

MicHop은 바로 이 문제를 해결합니다. 두 컴퓨터에 각각 하나씩 설치하세요:

- **말하는 컴퓨터**(예: MacBook): 「MicHop」 설치
- **작업하는 컴퓨터**(예: Mac mini): 「MicHop Receiver」 설치

### 두 가지 전송 방식, 메인 창에서 언제든 전환

```
MacBook(말하는 쪽)                           Mac mini(작업하는 쪽)

마이크 ──── 🔊 음성 보내기 ──────────►  가상 마이크(기본 제공 MicHop Audio)
                                      → 받아쓰기 / WeChat Input Method / Claude Code 음성 모드

받아쓰기 ── 📝 텍스트 보내기 ────────►  커서 위치에 붙여넣기, 자동 Return 가능

              LAN 또는 Tailscale 경유
```

**🔊 음성 보내기: Mac mini가 당신의 목소리를 직접 "듣습니다"**

MacBook 마이크의 소리가 실시간으로 Mac mini에 전달되어 Mac mini의 마이크가 됩니다. Mac mini에서 마이크가 필요한 모든 앱에서 쓸 수 있습니다. 예를 들어 macOS 받아쓰기, WeChat Input Method의 음성 입력, Claude Code의 음성 모드 등이 있습니다.

- Receiver에 가상 오디오 장치 **MicHop Audio**가 기본 제공됩니다. 처음 음성을 보낼 때 설치하라는 안내가 뜨며(관리자 암호를 한 번 입력해야 합니다), 따로 다운로드할 필요가 없습니다. 예전에 [BlackHole](https://github.com/ExistentialAudio/BlackHole)을 설치해 둔 경우에도 그대로 쓸 수 있습니다.
- 에코 제거 기능이 내장되어 있어, 원격 데스크톱 소프트웨어로 연결된 상태에서도 울림이 생기지 않습니다.
- 원격 데스크톱 소프트웨어에서는 Fn 키가 전달되지 않으므로, 음성 입력 단축키를 Ctrl + Option 같은 보조 키 조합으로 바꿔 두세요. [자세한 내용은 아래 참고](#팁-원격-연결-시-fn-키가-전달되지-않으면-단축키를-바꾸세요).

**📝 텍스트 보내기: MacBook에서 인식하고, 글자를 보냅니다**

MacBook에서 ⌃⌥Space(Ctrl + Option + Space)를 누르고 macOS 받아쓰기로 말을 텍스트로 바꾼 뒤 Mac mini로 보내면, 커서 위치에 자동으로 붙여넣어집니다. 자동으로 Return까지 눌러 Claude에 바로 제출할 수도 있습니다.

- Mac mini에 오디오 드라이버를 설치하거나 오디오를 설정할 필요가 없어, 가장 간편하고 가장 안정적입니다.
- 앱의 기본 모드입니다.

| | 🔊 음성 보내기 | 📝 텍스트 보내기 |
|---|---|---|
| 어느 컴퓨터에서 인식하나 | Mac mini(자체 받아쓰기 또는 입력기 사용) | MacBook(macOS 받아쓰기 사용) |
| Mac mini에 필요한 것 | Receiver + 기본 제공 가상 오디오 장치(처음 사용할 때 설치) | Receiver만 |
| 이럴 때 적합 | Mac mini의 입력기, 받아쓰기, Claude 음성 모드를 쓰고 싶을 때 | 말한 내용을 글자로 입력하기만 하면 될 때 |

### 두 컴퓨터를 연결하는 방법

- **같은 LAN에 있을 때**: Mac mini의 LAN IP만 입력하면 됩니다.
- **떨어져 있을 때**: 두 컴퓨터 모두 [Tailscale](https://tailscale.com)을 설치해 가상 LAN을 만들고, Mac mini의 **Tailscale IP**(100으로 시작)를 입력합니다. **음성과 텍스트 모두 Tailscale로 전송할 수 있어**, 집에서도 밖에서도 똑같이 쓸 수 있습니다.
- Receiver 창에 LAN IP, Tailscale IP, 암호가 표시되며, 항목마다 옆에 복사 버튼이 있습니다.

### 그 밖의 특징

- **어떤 클라우드 서비스도 거치지 않음**: 음성과 텍스트는 당신의 두 컴퓨터 사이에서만 직접 오갑니다. LAN을 통하거나, Tailscale의 암호화된 터널을 통합니다.
- **원격 데스크톱 소프트웨어와 무관**: UU Remote, Sunlogin, ToDesk, 화면 공유 모두와 함께 쓸 수 있습니다.
- **자동 업데이트**: 새 버전이 나오면 스스로 업그레이드하며, 권한을 다시 허용할 필요가 없습니다.
- **다국어 지원**: 인터페이스는 简体中文, 繁體中文, English, 日本語, 한국어, Español, Français, Deutsch, Português, Русский를 지원합니다. 기본값은 중국어이며, 「설정… → 일반 → 언어 / Language」에서 전환할 수 있습니다.

## 다운로드 및 설치

[Releases](../../releases/latest)에서 다운로드하세요:

| 파일 | 설치할 컴퓨터 | 메뉴 막대 아이콘 |
|---|---|---|
| `MicHop.zip`(MicHop) | 말하는 컴퓨터, 예: MacBook | 앱 아이콘과 같은 둥근 사각형 |
| `MicHop-Receiver.zip`(MicHop Receiver) | 작업하는 컴퓨터, 예: Mac mini | 위와 같음 |

메뉴 막대 아이콘의 색으로 상태를 알 수 있습니다: **회색** = 연결 안 됨, **녹색** = 연결됨, **빨간색** = 전송 중(말하는 중 / 음성 수신 중).

> **두 앱 모두 메인 창이 중심입니다**: Dock 아이콘을 클릭하면 메인 창이 열립니다. 창 상단에는 상태가 두 칸으로 나뉘어 표시됩니다: 「연결 상태」(회색 / 파란색)와 「음성」(회색 / 빨간색). 자주 쓰는 기능은 모두 창 안에 있습니다. 언어, 자동 업데이트 등은 「설정…」(⌘,)에 있습니다. 메뉴 막대 아이콘과 Dock 아이콘 우클릭 메뉴에는 가장 자주 쓰는 몇 가지 항목만 남아 있습니다. MacBook 카메라(노치)가 메뉴 막대 아이콘을 가릴 때는 Dock 아이콘을 쓰면 됩니다.

macOS 13 이상이 필요하며, Apple 실리콘과 Intel Mac 모두 지원합니다.

> **처음 열 때 "개발자를 확인할 수 없음"이라고 나오는 경우**: 이 앱이 유료 Apple 공증을 받지 않았기 때문입니다. 시스템 설정 → 개인정보 보호 및 보안을 열고, 페이지 아래쪽의 「확인 없이 열기」를 클릭하세요. 또는 터미널에서 다음 명령을 실행해 격리 속성을 해제한 뒤 열 수도 있습니다:
> ```bash
> xattr -dr com.apple.quarantine "/Applications/MicHop Receiver.app"
> ```

### 1. 작업하는 컴퓨터(Receiver)

1. `MicHop-Receiver.zip`의 압축을 풀고, 「MicHop Receiver」를 「응용 프로그램」으로 드래그한 다음 엽니다.
2. 안내에 따라 **손쉬운 사용** 권한을 켭니다: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → 「MicHop Receiver」 켜기. 대신 ⌘V를 누르려면 이 권한이 필요합니다.
   - "들어오는 네트워크 연결을 허용하겠습니까?"라는 창이 뜨면 **허용**을 클릭하세요.
3. Dock에서 「MicHop Receiver」 아이콘을 클릭하면 메인 창에서 다음을 볼 수 있습니다:
   - **연결 정보**: 이 컴퓨터의 LAN 주소, Tailscale 주소, 암호. 항목마다 옆에 복사 버튼이 있습니다.
   - **준비 상태**: 「손쉬운 사용 권한」 항목에 녹색 체크 표시가 있어야 합니다. 노란색 경고가 있는 항목은 오른쪽에 바로 해결 버튼이 표시됩니다.
4. 「로그인 시 실행」이 기본으로 켜져 있습니다. 필요 없으면 「설정… → 일반」에서 끌 수 있습니다.

### 2. 말하는 컴퓨터(송신 측)

1. `MicHop.zip`의 압축을 풀고, 「MicHop」을 「응용 프로그램」으로 드래그한 다음 엽니다.
2. 처음 열면 설정 창이 뜹니다. Receiver의 **주소**와 **암호**를 입력하고 「연결 테스트」를 클릭합니다. 녹색으로 「연결됨 — 바로 쓸 수 있습니다」가 보이면 「저장」을 클릭합니다.
   - Receiver 창에서는 주소와 암호 옆의 복사 버튼으로 각 항목을 따로 복사할 수 있습니다.
   - Receiver에서 「모두 복사」를 클릭한 뒤 통째로 「수신 측 주소」 칸에 붙여넣어도 됩니다. 송신 측이 자동으로 주소를 골라내고(Tailscale 주소가 있으면 우선 사용), 암호도 자동으로 채워 줍니다.
   - "로컬 네트워크에서 기기를 찾도록 허용"하겠냐는 창이 뜨면 **허용**을 클릭하세요.
3. macOS 받아쓰기가 켜져 있는지 확인하세요: 시스템 설정 → 키보드 → 받아쓰기.
4. 메인 창 상단에 「수신기에 연결됨」이 표시되면 바로 쓸 수 있습니다. 나중에 주소나 암호를 바꾸려면 메인 창의 「수신기」 항목에서 「변경…」을 클릭하거나 ⌘,를 누르세요.

## 사용 방법

1. 먼저 원격 데스크톱에서 작업하는 컴퓨터의 입력란(예: Claude Code)을 한 번 클릭합니다.
2. **⌃⌥Space(Ctrl + Option + Space)**를 누르면 화면 아래쪽에 작은 창이 뜨고 받아쓰기가 자동으로 시작됩니다. 자동으로 시작되지 않으면 Fn을 한 번 누르세요.
3. 말한 뒤 **Return**을 누르면, 텍스트가 다른 컴퓨터에 나타납니다.

| 키 | 동작 |
|---|---|
| Return / ⌃⌥Space 한 번 더 | 전송 |
| Shift + Return | 줄바꿈 |
| Esc | 취소 |

작은 창 상단에는 텍스트를 보낼 컴퓨터가 표시됩니다. 왼쪽 아래에는 「보낸 뒤 자동으로 Return」 옵션이 있으며 기본으로 체크되어 있어, 텍스트가 Claude에 바로 제출됩니다. 먼저 확인한 다음 직접 제출하고 싶다면 체크를 해제하세요(메인 창의 「옵션」에도 같은 스위치가 있습니다).

원격 데스크톱 소프트웨어가 이 키 조합을 가로채서 작은 창이 뜨지 않는다면, 메인 창의 큰 「말하기」 버튼을 클릭하거나, 메뉴 막대 아이콘 → 「말하기」를 클릭하세요.

> **단축키는 바꿀 수 있습니다**: 「설정… → 단축키」에서 버튼을 클릭한 뒤 새 키 조합을 누르세요. 일부 Mac에서는 ⌃⌥Space가 이미 시스템의 「입력 메뉴에서 다음 소스 선택」에 할당되어 있어, 누르면 입력 소스가 바뀝니다. 이런 경우 앱에 주황색 안내가 표시되니, 시스템 설정 → 키보드 → 키보드 단축키 → 입력 소스에서 그 항목을 끄거나, MicHop에서 다른 키 조합으로 바꾸세요.

## 두 가지 전송 모드

메인 창의 「전송 방식」에서 「텍스트」 또는 「음성」 카드를 클릭해 전환합니다. 메뉴 막대 아이콘의 메뉴에서도 전환할 수 있습니다. **기본값은 텍스트 보내기입니다.**

| | 텍스트 보내기(기본값) | 음성 보내기 |
|---|---|---|
| 어디서 인식하나 | 이 컴퓨터에서 macOS 받아쓰기로 텍스트 변환 | 상대 컴퓨터에서 자체 받아쓰기나 Claude Code 음성 모드로 인식 |
| ⌃⌥Space의 역할 | 받아쓰기 작은 창 열기 | 「항상 전송」 시작 또는 중지 |
| ⌃⌥ 누르고 있기 | — | 누르는 동안만 전송, 떼면 중지 |
| 메인 창의 큰 버튼 | 「말하기」 | 「음성 전송 시작」 / 「음성 전송 중지」 |
| 상대 쪽에 필요한 것 | Receiver만 | Receiver와 기본 제공 가상 오디오 장치 |

## 음성 보내기 모드

작업하는 컴퓨터가 **당신의 목소리를 직접 듣게** 하고 싶을 때 쓰는 모드입니다. 예를 들어 그 컴퓨터에서 Claude Code의 음성 모드를 쓰거나, 그 컴퓨터 자체의 받아쓰기 기능을 쓸 때입니다.

```
MacBook 마이크 ──음성──► Receiver ──► 가상 오디오 장치 MicHop Audio ──► 그 컴퓨터에서 "마이크를 듣는" 모든 앱
```

**Receiver 컴퓨터에서 먼저 준비할 것:**

1. 기본 제공 가상 오디오 장치 **MicHop Audio**를 설치합니다. 송신 측에서 처음 음성을 보내면 Receiver에 안내가 뜨니 「설치」를 클릭하세요. Receiver의 「설정… → 가상 오디오 장치」에서 「설치」를 클릭해도 됩니다. 관리자 암호를 한 번 입력해야 하며, 설치가 끝날 때 시스템 소리가 1~2초 끊깁니다.
2. 설치가 끝나면 안내에 따라 **시스템 입력**을 MicHop Audio로 바꿉니다(메인 창의 「준비 상태」에도 「바꾸기」 버튼이 있습니다).
3. 시스템 **출력** 장치는 스피커(또는 원격 데스크톱 소프트웨어의 오디오 장치)로 그대로 둡니다. MicHop Audio는 애초에 시스템 출력으로 선택할 수 없으므로, 시스템 소리가 섞여 들어가지 않습니다.

> **예전에 BlackHole을 설치했나요?** 그대로 쓸 수 있습니다. 「준비 상태 → 소리 출력 장치」에서 원하는 장치를 선택하세요. 기본 제공 장치로 바꾸고 싶다면 「기본 제공 가상 장치로 바꿀 수 있습니다」 옆의 「설치」를 클릭하세요. BlackHole을 쓸 때는 시스템 출력으로 선택하지 않도록 주의하세요. 잘못 선택했다면 「준비 상태」에 「시스템 출력」 경고가 나타나니, 「스피커로 되돌리기」를 클릭하면 됩니다.

> **왜 울림(에코)이 생기나요?** 많은 원격 데스크톱 소프트웨어(예: UU Remote)는 Apple의 화면 기록 프레임워크로 원격 컴퓨터의 소리를 캡처하는데, 이때 어느 오디오 장치로 재생되든 상관없이 그 컴퓨터에서 **모든 앱이 내는 소리**를 녹음합니다. MicHop이 당신의 목소리를 가상 오디오 장치로 재생하면 그것도 함께 녹음되어 당신의 컴퓨터로 되돌아오고, 스피커로 재생된 뒤 다시 마이크에 잡힙니다.
>
> 그래서 송신 측은 기본적으로 **「에코 제거」**가 켜져 있습니다(메인 창의 「옵션」에서 끌 수 있습니다). FaceTime에서도 쓰는 Apple의 음성 처리 기술을 사용합니다: 되돌아온 소리를 마이크 신호에서 빼고, 당신이 말할 때는 다른 소리를 낮추며, 덤으로 소음도 줄여 줍니다. 헤드폰을 쓰면 효과가 가장 좋습니다.

**사용 방법:**

메인 창의 「전송 방식」에서 「음성」을 선택하면 송신 측이 Receiver에 연결되고(처음에는 마이크 권한을 요청합니다), 「연결 상태」가 파란색으로, 메뉴 막대 아이콘이 녹색으로 바뀝니다. 그다음에는 두 가지 방법으로 말할 수 있으며, 둘 다 언제든 쓸 수 있습니다:

1. **항상 전송**: **⌃⌥Space**를 한 번 누르면(또는 「음성 전송 시작」 클릭) 마이크가 계속 켜져 있고, 다시 누르면 멈춥니다.
2. **눌러서 말하기**: **Ctrl + Option을 누른 채 말하고, 떼면 멈춥니다**. 키를 누르고 있는 동안에만 마이크가 켜지고, 메인 창의 「음성」과 메뉴 막대 아이콘이 빨간색으로 바뀝니다. 키를 떼면 마이크가 꺼지고, 이 컴퓨터의 음량도 낮아지지 않습니다. 처음에는 이 키 조합을 감지하기 위해 손쉬운 사용 권한을 요청합니다. 권한이 꺼져 있으면 메인 창의 「옵션」에 안내가 표시되니 「켜기…」를 클릭하세요.
3. 누르고 있는 이 키 조합은 원격 데스크톱 소프트웨어를 통해 작업하는 컴퓨터에도 전달됩니다. 그 컴퓨터에서 받아쓰기나 입력기의 음성 단축키도 Ctrl + Option으로 설정해 두면([아래 팁](#팁-원격-연결-시-fn-키가-전달되지-않으면-단축키를-바꾸세요) 참고), **한 번 누르는 것만으로 "음성 보내기"와 "그쪽에서 받아쓰기 시작"이 동시에 이루어집니다**.
4. 두 단축키 모두 「설정… → 단축키」에서 바꿀 수 있습니다.

> 키를 누르고 있는 동안 MicHop은 이 Mac을 잠시 음소거합니다. 원격 프로그램이 되돌려 보내는 소리가 마이크로 들어가 에코가 생기는 것을 막기 위해서이며, 키를 떼고 약 1초 뒤 자동으로 복원됩니다. (「항상 전송」 방식에서는 Apple 에코 제거를 사용합니다.)

### 팁: 원격 연결 시 Fn 키가 전달되지 않으면 단축키를 바꾸세요

UU Remote, Sunlogin, ToDesk 같은 원격 데스크톱 소프트웨어로 연결했을 때, **내 컴퓨터에서 Fn 키를 눌러도 원격 컴퓨터에는 전달되지 않습니다**. 원격 컴퓨터에서 macOS 받아쓰기를 쓰든, WeChat Input Method의 음성 입력을 쓰든 실행되지 않습니다. 이유는 두 가지입니다: Fn 키가 먼저 내 컴퓨터에서 가로채지고(내 컴퓨터에서 받아쓰기가 시작됨), 설령 원격 소프트웨어가 전달하더라도 원격 컴퓨터에서는 "가상 키 입력"일 뿐이라 시스템과 입력기가 대개 인식하지 않습니다.

해결 방법: **원격 컴퓨터**(예: Mac mini)에서 음성 입력 단축키를 바꿉니다:

- **macOS 받아쓰기**: 시스템 설정 → 키보드 → 받아쓰기 → 단축키 → 「사용자화」.
- **WeChat Input Method**: WeChat Input Method 설정에서 음성 입력 단축키를 변경합니다.

**보조 키 조합**을 추천합니다. 예를 들어 **왼쪽 Ctrl + Option**, 또는 Ctrl과 다른 보조 키(Option, Shift, Command)의 조합입니다.

**Ctrl과 숫자 키나 문자 키 조합(예: Ctrl+D)은 쓰지 마세요**. 음성 입력은 보통 키를 누른 채 말해야 하는데, 문자나 숫자 키를 누르고 있으면 그 글자가 반복 입력되어 매우 불편합니다. 보조 키만으로 된 조합은 누르고 있어도 글자가 입력되지 않습니다.

이 방법은 「음성 보내기」 모드와 함께 씁니다: 원격 컴퓨터의 입력 장치를 MicHop Audio로 설정하고, 원격 데스크톱에서 새 단축키를 누른 채 말하면 원격 컴퓨터에서 바로 받아쓰기가 됩니다.

## 같은 네트워크가 아닌가요? Tailscale을 쓰세요

1. 두 컴퓨터 모두 [Tailscale](https://tailscale.com)을 설치하고 같은 계정으로 로그인합니다.
2. Receiver 메인 창의 「연결 정보」에서 「Tailscale」 항목에 100.x.x.x가 표시되면, 이를 송신 측 설정에 입력합니다. Tailscale에 표시되는 기기 이름을 입력해도 됩니다.
3. 「감지 안 됨」으로 표시되면, 먼저 Receiver 컴퓨터에서 Tailscale이 연결되어 있는지 확인한 뒤 그 항목의 새로고침 버튼을 클릭해 다시 감지하세요. 그래도 감지되지 않으면 Receiver의 「설정… → Tailscale → 주소 직접 입력」에서 Tailscale 메뉴에 표시된 주소를 입력하세요.

Tailscale 주소는 집에서도 밖에서도 쓸 수 있으며, 같은 LAN 안에 있을 때는 자동으로 직접 연결됩니다.

## 보안

- 각 Receiver에는 무작위 6자리 암호가 있으며, 암호가 틀린 요청은 모두 거부됩니다. Receiver 메인 창의 「암호」 항목에서 「새로 만들기」를 클릭하면 바꿀 수 있습니다(바꾼 뒤에는 송신 측에 다시 입력해야 합니다).
- Receiver는 TCP **8765**(텍스트)와 **8766**(음성) 두 포트에서 수신하며, 전송은 암호화되지 않습니다. 가정용 LAN이나 Tailscale 안에서만 사용하고, 이 포트들을 공용 인터넷에 노출하지 마세요.
- 붙여넣을 때 클립보드를 잠시 빌려 쓰며, 약 1초 뒤 원래 내용으로 되돌립니다.

## 자주 묻는 질문

- **연결이 안 됨**: 두 컴퓨터가 같은 네트워크에 있는지, 또는 둘 다 Tailscale에 연결되어 있는지 확인하세요. LAN IP는 바뀔 수 있으므로, 라우터에서 Receiver에 고정 IP를 지정하거나 Tailscale 주소를 쓰는 것을 권장합니다.
- **손쉬운 사용 권한이 꺼져 있다고 나옴**: 앱을 다시 빌드하거나 업데이트하면 macOS가 기존 권한을 무효화할 수 있습니다. 손쉬운 사용 목록에서 이전 항목을 먼저 삭제한 다음 다시 추가하세요.

## 자동 업데이트

두 앱 모두 스스로 GitHub에서 새 버전을 확인합니다: 실행 30초 후 한 번, 그 뒤로는 6시간마다 확인합니다. 새 버전을 찾으면 자동으로 다운로드하고, 교체하고, 다시 실행합니다.

- 메인 창 왼쪽 아래에서 현재 버전 번호를 볼 수 있고, 「설정… → 일반」에서 「업데이트 확인」을 클릭해 바로 확인할 수도 있습니다.
- 자동 설치를 원하지 않으면 「설정… → 일반」에서 「자동으로 업데이트 설치」를 끄세요. 이후 새 버전이 있으면 설정에 「x.y.z(으)로 업데이트」 버튼이 나타나고 메뉴 막대 메뉴에도 같은 항목이 생기며, 클릭해야만 업데이트됩니다.
- 사용 중에는 방해하지 않습니다: 송신 측은 받아쓰기 작은 창이 열려 있는 동안 업데이트하지 않고, Receiver는 음성 수신 중이거나 1분 안에 텍스트를 받은 경우 업데이트하지 않습니다.
- 보안: 새 버전은 현재 버전과 **같은 인증서**로 서명되어 있어야 하며, 그렇지 않으면 설치를 거부합니다.
- 업그레이드 후에도 손쉬운 사용, 마이크 등의 권한이 유지되므로 다시 허용할 필요가 없습니다.
