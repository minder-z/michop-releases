## 這是做什麼的

我平常用 MacBook 辦公，再透過遠端軟體（悠悠遠端、向日葵、ToDesk 等）連到 Mac mini 上工作，例如讓 Claude Code 寫程式、剪影片、維護網站。

麻煩的是：**Mac mini 沒有麥克風，遠端軟體也不會把 MacBook 的麥克風傳過去**，所以在遠端桌面裡沒辦法語音輸入。

傳聲筒就是為了解決這個問題。兩台電腦各裝一個：

- **說話的電腦**（例如 MacBook）：安裝「傳聲筒」
- **工作的電腦**（例如 Mac mini）：安裝「傳聲筒接收端」

```
MacBook（說話）                              Mac mini（工作）

麥克風 ──── 🔊 聲音 ──────────────►  虛擬麥克風（內建的 MicHop Audio）
                                      → 系統聽寫 / 微信輸入法 / Claude Code 語音模式

              走區域網路 或 Tailscale
```

MacBook 麥克風的聲音會即時傳到 Mac mini，成為 Mac mini 的麥克風。Mac mini 上任何需要麥克風的程式都能用，例如系統聽寫、微信輸入法的語音輸入、Claude Code 的語音模式。

- 接收端內建虛擬音效卡 **MicHop Audio**，第一次開啟時會提示安裝（需要輸入一次管理者密碼），不必另外下載。以前裝過 [BlackHole](https://github.com/ExistentialAudio/BlackHole) 的也能繼續使用。
- 兩種說話方式，隨時都能用：按一下 **⌃⌥M** 持續傳送，再按一下停止；或是**按住 ⌃⌥** 說話，放開就停。
- 內建回音消除，就算透過遠端軟體連線也不會有回音。
- 遠端軟體傳不過去 Fn 鍵，記得把 Mac mini 上語音輸入的快速鍵改成修飾鍵組合，例如 Ctrl + Option，[詳見下文](#小技巧遠端連線時fn-鍵傳不過去換個快速鍵)。

### 兩台電腦怎麼連

- **在同一個區域網路裡**：填 Mac mini 的區域網路 IP 就行。
- **不在同一個地方**：兩台電腦都裝 [Tailscale](https://tailscale.com)，組成一個虛擬區域網路，填 Mac mini 的 **Tailscale IP**（100 開頭），在家、在外都一樣能用。
- 接收端視窗裡會列出區域網路 IP、Tailscale IP 和口令，每一項旁邊都有拷貝按鈕。

### 其他特點

- **不經過任何雲端服務**：聲音只在你自己的兩台電腦之間直接傳送，走區域網路，或是走 Tailscale 的加密通道。
- **不挑遠端軟體**：悠悠遠端、向日葵、ToDesk、螢幕共享都能搭配使用。
- **自動更新**：有新版本時會自行升級，權限不必重新授權。
- **多語言**：介面支援简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский，預設為簡體中文，可在「設定… → 一般 → 語言 / Language」裡切換。

## 下載安裝

到 [Releases](../../releases/latest) 下載：

| 檔案 | 裝在哪台電腦 | 選單列圖像 |
|---|---|---|
| `MicHop.zip`（傳聲筒） | 說話的電腦，例如 MacBook | 和 App 圖像一樣的兩支麥克風 |
| `MicHop-Receiver.zip`（傳聲筒接收端） | 工作的電腦，例如 Mac mini | 同上 |

選單列圖像的顏色代表狀態：**灰色**＝沒連上，**綠色**＝已連上，**紅色**＝正在傳聲音。

> **兩個 App 都以主視窗為中心**：點一下 Dock 圖像就會跳出主視窗，頂端分兩區顯示狀態：「連線狀態」（灰 / 藍）和「傳聲音」（灰 / 紅），常用操作都在視窗裡；快速鍵、語言、自動更新等則放在「設定…」（⌘,）裡。選單列圖像和 Dock 圖像的右鍵選單只保留最常用的幾項。如果 MacBook 的相機（瀏海）擋住了選單列圖像，改用 Dock 圖像就好。

需要 macOS 13 或以上版本，Apple 晶片和 Intel 晶片都能用。

> **第一次開啟時提示「無法驗證開發者」**：這是因為這個 App 沒有花錢做 Apple 公證。打開「系統設定」→「隱私權與安全性」，在頁面下方點「強制打開」。也可以在「終端機」裡執行下面這行指令，解除隔離後再開啟：
> ```bash
> xattr -dr com.apple.quarantine "/Applications/MicHop Receiver.app"
> ```

### 1. 工作的電腦（接收端）

1. 解壓縮 `MicHop-Receiver.zip`，把「MicHop Receiver」拖進「應用程式」，然後開啟。
   - 如果跳出「是否要讓應用程式接受傳入的網路連線？」，請點**允許**。
2. 第一次開啟會提示安裝內建的虛擬音效卡 **MicHop Audio**：點「安裝」，輸入一次管理者密碼；安裝完成時，系統聲音會中斷一兩秒。也可以之後再到「設定… → 虛擬音效卡」裡安裝。
3. 裝好後依照提示把**系統輸入裝置**改成 MicHop Audio（主視窗的「準備狀況」裡也有「改過來」按鈕）。系統的**輸出**裝置維持揚聲器（或遠端軟體的音訊裝置）即可。MicHop Audio 本身無法被選為系統輸出，所以不會把系統聲音混進來。
4. 主視窗裡可以看到：
   - **連線資訊**：本機的區域網路位址、Tailscale 位址和口令，每一項旁邊都有拷貝按鈕。
   - **準備狀況**：虛擬音效卡和系統輸入裝置都顯示綠色勾號，就代表準備好了。出現黃色警告的項目，右邊會直接提供修正按鈕。
5. 預設開機時自動啟動，不需要的話可以在「設定… → 一般」裡關掉。

> **以前裝過 BlackHole？** 照樣能用：在「準備狀況 → 聲音播到」裡選擇你想用的音效卡。想換成內建的，點「可以改用內建的虛擬音效卡」旁邊的「安裝」。使用 BlackHole 時注意別把它選成系統輸出；選錯的話，「準備狀況」裡會出現「系統輸出」的警告，點「改回揚聲器」就行。

### 2. 說話的電腦（傳送端）

1. 解壓縮 `MicHop.zip`，把「MicHop」拖進「應用程式」，然後開啟。
2. 第一次開啟會跳出設定視窗：填入接收端的**位址**和**口令**，點「測試連線」，看到綠色的「連上了，可以用了」之後點「儲存」。
   - 在接收端視窗裡，位址和口令旁邊的拷貝按鈕可以分別拷貝每一項。
   - 也可以在接收端點「全部拷貝」，再把整段貼到「位址」欄裡。傳送端會自動挑出位址（有 Tailscale 位址就優先使用），口令也會自動填好。
   - 如果跳出「想要尋找並連接區域網路上的裝置」，請點**允許**。
3. 第一次使用時會要求**麥克風**權限，請點允許；也會要求**輔助使用**權限（用來偵測「按住 ⌃⌥」），請依提示開啟：「系統設定」→「隱私權與安全性」→「輔助使用」→ 打開「傳聲筒」。
4. 打開 App 就會連上接收端。主視窗的「連線狀態」變藍、選單列圖像變綠，就可以開始用了。之後要修改位址或口令，點主視窗裡「接收端」那一欄的「更改…」，或按 ⌘,。

## 怎麼用

先在遠端桌面裡，點一下工作電腦上要使用語音的地方，例如 Claude Code 的語音模式、系統聽寫或輸入法。接著兩種說話方式隨時都能用：

1. **持續傳送**：按一下 **⌃⌥M（Ctrl + Option + M）**，或點主視窗的「開始傳聲音」，麥克風會一直開著；再按一下就停止。
2. **按住傳送**：**按住 Ctrl + Option 說話，放開就停**。只有按住的時候才會打開麥克風。

傳送中，主視窗的「傳聲音」和選單列圖像都會變紅；接收端那邊的「傳聲音」也會變紅。

- 按住的這組按鍵也會被遠端軟體傳到工作的電腦上。如果你在那台電腦上把聽寫或輸入法的語音快速鍵也設成 Ctrl + Option（見[下方的小技巧](#小技巧遠端連線時fn-鍵傳不過去換個快速鍵)），**按一次就能同時完成「傳聲音」和「讓那邊開始聽寫」**。
- 按住說話時，傳聲筒會暫時把本機靜音，避免對方電腦的聲音被遠端軟體傳回來、又被麥克風收進去而形成回音；放開約 1 秒後會自動恢復。（「持續傳送」使用的是 Apple 的回音消除。）

> **快速鍵可以自訂**：在「設定… → 快速鍵」裡點按鈕，再按下新的組合鍵。「開始傳聲」可以用任何含 ⌃、⌥ 或 ⌘ 的組合；「按住傳聲」則要用 ⌃ ⌥ ⇧ ⌘ 中兩個以上的組合。如果選的組合已經被系統佔用（例如 ⌃⌥空白鍵 在很多 Mac 上是「選擇輸入方式選單中的下一個輸入方式」），App 會顯示橘色提示：請到「系統設定」→「鍵盤」→「鍵盤快速鍵」裡關掉那一項，或換一組按鍵。

> **為什麼會有回音？** 很多遠端軟體（例如悠悠遠端）是用 Apple 的螢幕錄製框架擷取被控端的聲音，會把那台電腦上**所有程式發出的聲音**都錄下來，不管它播到哪張音效卡。傳聲筒把你的聲音播進虛擬音效卡時，也會一起被錄走、傳回你的電腦，從揚聲器播出來，再被麥克風收進去。
>
> 所以傳送端預設開啟了**回音消除**（可以在主視窗的「選項」裡關閉）。它用的是 Apple 的語音處理，FaceTime 用的也是同一套：把傳回來的聲音從麥克風訊號中扣掉；你說話時壓低其他聲音；順便降噪。戴耳機效果最好。

### 小技巧：遠端連線時，Fn 鍵傳不過去，換個快速鍵

用悠悠遠端、向日葵、ToDesk 這類遠端軟體連線時，**在本機按 Fn 鍵，是傳不到被控端的**。不論被控端用的是系統聽寫，還是微信輸入法的語音輸入，都觸發不了。原因有兩個：Fn 鍵會先被本機攔下來（本機自己開始聽寫）；就算遠端軟體把它傳了過去，在被控端也只是「模擬按鍵」，系統和輸入法通常不認。

解決方法：在**被控端**（例如 Mac mini）更換語音輸入的快速鍵：

- **系統聽寫**：「系統設定」→「鍵盤」→「聽寫」→「快速鍵」→「自訂」。
- **微信輸入法**：在微信輸入法的設定裡，修改語音輸入的快速鍵。

建議使用**修飾鍵組合**，例如**左側 Ctrl + Option**，或 Ctrl 加上其他修飾鍵（Option、Shift、Command）。

**不要用 Ctrl 加數字鍵或字母鍵**（例如 Ctrl+D）。語音輸入通常要按住說話，按住字母或數字鍵時，該字元會被重複輸入，非常不好用。純修飾鍵組合按住時不會打出字元。

把被控端的輸入裝置設為 MicHop Audio，在遠端桌面裡按住新的快速鍵說話，被控端就能直接聽寫了。

## 不在同一個網路？用 Tailscale

1. 兩台電腦都裝上 [Tailscale](https://tailscale.com)，並登入同一個帳號。
2. 接收端主視窗「連線資訊」裡的「Tailscale」那一列會顯示 100.x.x.x，把它填到傳送端的設定裡。也可以填 Tailscale 裡顯示的機器名稱。
3. 如果顯示「未偵測到」，先確認接收端電腦上的 Tailscale 已連線，再點那一列的重新整理按鈕重新偵測。真的偵測不到的話，就到接收端的「設定… → Tailscale → 手動填寫位址」裡，填入 Tailscale 選單中顯示的位址。

Tailscale 位址在家、在外都能用；兩台在同一個區域網路時，它會自動直連。

## 安全

- 每台接收端都有一組隨機的 6 位數口令，口令錯誤的連線一律拒絕。可以在接收端主視窗「口令」那一列點「換一個」（換了之後，傳送端要重新填寫）。
- 接收端只監聽一個連接埠：TCP **8766**（聲音），傳輸目前沒有加密。建議只在家用區域網路或 Tailscale 裡使用，不要把這個連接埠暴露到網際網路上。

## 常見問題

- **連不上**：確認兩台電腦在同一個網路，或是都已連上 Tailscale。區域網路 IP 可能會變動，建議在路由器裡給接收端設定固定 IP，或直接使用 Tailscale 位址。
- **接收端提示連接埠打不開**：通常是舊的接收端沒有完全結束、還佔著連接埠，接收端會自動把它結束；如果是其他程式佔用，提示裡會寫出它的名稱，等它釋放後接收端會自動啟動。
- **按住 ⌃⌥ 沒反應**：傳送端需要**輔助使用**權限。重新編譯或更新 App 後，macOS 有時會讓原本的授權失效，請先在「輔助使用」清單裡刪掉舊的那一項，再重新加入。

## 自動更新

兩個 App 都會自行到 GitHub 檢查新版本：啟動 30 秒後檢查一次，之後每 6 小時檢查一次。發現新版本，就會自動下載、替換並重新開啟。

- 主視窗左下角可以看到目前的版本號；在「設定… → 一般」裡點「檢查更新」可以立即檢查。
- 不想自動安裝的話，在「設定… → 一般」裡關掉「自動安裝更新」。之後有新版本時，設定裡會出現「更新到 x.y.z」按鈕，選單列選單裡也會出現同樣的項目，點一下才會更新。
- 不會在使用中打斷你：正在傳聲音時不會更新。
- 安全：新版本必須和目前版本用**同一張憑證**簽署，否則拒絕安裝。
- 升級後，輔助使用、麥克風等權限都會保留，不必重新授權。
