## 這是做什麼的

我平常用 MacBook 辦公，再用遠端軟體（悠悠遠程、向日葵、ToDesk 等）連到 Mac mini 上工作，例如讓 Claude Code 寫程式、剪影片、維護網站。

麻煩的是：**Mac mini 沒有麥克風，遠端軟體也不會把 MacBook 的麥克風傳過去**，所以在遠端桌面裡沒辦法語音輸入。

傳聲筒解決的就是這個問題。兩台電腦各裝一個：

- **說話的電腦**（例如 MacBook）：裝「傳聲筒」
- **工作的電腦**（例如 Mac mini）：裝「傳聲筒接收端」

### 兩種傳法，主視窗裡隨時切換

```
MacBook（說話）                              Mac mini（工作）

麥克風 ──── 🔊 傳聲音 ────────────►  虛擬麥克風（內建的 MicHop Audio）
                                      → 系統聽寫 / 微信輸入法 / Claude Code 語音模式

聽寫   ──── 📝 傳文字 ────────────►  貼到游標所在的位置，可自動按 Return

              走區域網路 或 Tailscale
```

**🔊 傳聲音：Mac mini 直接「聽到」你說話**

MacBook 麥克風的聲音即時傳到 Mac mini，變成 Mac mini 的麥克風。Mac mini 上任何需要麥克風的程式都能用，例如系統聽寫、微信輸入法的語音輸入、Claude Code 的語音模式。

- 接收端內建虛擬音效卡 **MicHop Audio**，第一次傳聲音時會提示安裝（要輸入一次管理員密碼），不用另外下載。以前裝過 [BlackHole](https://github.com/ExistentialAudio/BlackHole) 的也能繼續用。
- 內建回音消除，用遠端軟體連著也不會有回音。
- 遠端軟體裡 Fn 鍵傳不過去，記得把語音輸入的快捷鍵換成修飾鍵組合，例如 Ctrl + Option，[詳見下文](#小技巧遠端連線時fn-鍵傳不過去換個快捷鍵)。

**📝 傳文字：在 MacBook 上辨識，把字傳過去**

在 MacBook 上按 ⌃⌥空白鍵（Ctrl + Option + 空白鍵），用系統聽寫把話轉成文字，再傳到 Mac mini，自動貼到游標所在的位置，還可以自動按 Return，直接提交給 Claude。

- Mac mini 上不用裝音效卡，也不用設定音訊，最省事、最穩定。
- App 預設就是這個模式。

| | 🔊 傳聲音 | 📝 傳文字 |
|---|---|---|
| 在哪台電腦辨識 | Mac mini（用它自己的聽寫或輸入法） | MacBook（用系統聽寫） |
| Mac mini 需要準備 | 接收端 + 內建的虛擬音效卡（第一次用時安裝） | 只要接收端 |
| 適合 | 想用 Mac mini 上的輸入法、聽寫、Claude 語音模式 | 只想把說的話變成字打進去 |

### 兩台電腦怎麼連

- **在同一個區域網路裡**：填 Mac mini 的區域網路 IP 就行。
- **不在一起**：兩台電腦都裝 [Tailscale](https://tailscale.com) 組成一個虛擬區域網路，填 Mac mini 的 **Tailscale IP**（100 開頭）。**聲音和文字都能走 Tailscale 傳**，在家在外都一樣用。
- 接收端視窗裡會列出區域網路 IP、Tailscale IP 和口令，每一項旁邊都有拷貝按鈕。

### 其他特點

- **不經過任何雲端服務**：聲音和文字只在你自己的兩台電腦之間直傳，走區域網路，或者走 Tailscale 的加密通道。
- **和遠端軟體無關**：悠悠遠程、向日葵、ToDesk、螢幕共享都能搭配使用。
- **自動更新**：有新版本時會自己升級，權限不用重新授權。
- **多語言**：介面支援简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский，預設中文，在「設定… → 一般 → 語言 / Language」裡切換。

## 下載安裝

到 [Releases](../../releases/latest) 下載：

| 檔案 | 裝在哪台電腦 | 選單列圖像 |
|---|---|---|
| `MicHop.zip`（傳聲筒） | 說話的電腦，例如 MacBook | 和 App 圖示一樣的圓角方塊 |
| `MicHop-Receiver.zip`（傳聲筒接收端） | 工作的電腦，例如 Mac mini | 同上 |

選單列圖像的顏色代表狀態：**灰色**＝沒連上，**綠色**＝連上了，**紅色**＝正在傳（說話 / 收聲音）。

> **兩個 App 都以主視窗為中心**：點 Dock 圖示就會彈出主視窗，頂部分兩塊顯示狀態：「連線狀態」（灰 / 藍）和「傳聲音」（灰 / 紅），常用操作都在視窗裡；語言、自動更新等放在「設定…」（⌘,）裡。選單列圖示和右鍵 Dock 圖示只保留最常用的幾項。MacBook 的相機（瀏海）擋住選單列圖示時，用 Dock 圖示就行。

需要 macOS 13 或更新版本，Apple 晶片和 Intel 晶片都能用。

> **第一次打開提示「無法驗證開發者」**：這是因為這個 App 沒有付費做 Apple 公證。打開 系統設定 → 隱私權與安全性，在頁面下方點「強制打開」。也可以在終端機裡執行這條指令，解除隔離後再打開：
> ```bash
> xattr -dr com.apple.quarantine "/Applications/MicHop Receiver.app"
> ```

### 1. 工作的電腦（接收端）

1. 解壓縮 `MicHop-Receiver.zip`，把「MicHop Receiver」拖進「應用程式」，然後打開。
2. 依照提示打開**輔助使用**權限：系統設定 → 隱私權與安全性 → 輔助使用 → 打開「傳聲筒接收端」。它需要這個權限才能替你按 ⌘V。
   - 如果跳出「是否允許接受傳入的網路連線」，點**允許**。
3. 點 Dock 裡的「傳聲筒接收端」圖示，主視窗裡能看到：
   - **連線資訊**：本機區域網路位址、Tailscale 位址和口令，每一項旁邊都有拷貝按鈕。
   - **準備狀況**：「輔助使用權限」那一行應該是綠色勾號。有黃色警告的項目，右邊會直接給出修復按鈕。
4. 「開機時自動啟動」預設是開啟的，不需要的話可以在「設定… → 一般」裡關掉。

### 2. 說話的電腦（傳送端）

1. 解壓縮 `MicHop.zip`，把「MicHop」拖進「應用程式」，然後打開。
2. 第一次打開會跳出設定視窗：填上接收端的**位址**和**口令**，點「測試連線」，看到綠色的「連上了，可以用了」後點「儲存」。
   - 在接收端視窗裡，位址和口令旁邊的拷貝按鈕可以單獨拷貝每一項。
   - 也可以在接收端點「全部拷貝」，然後把整段貼到「接收端位址」欄裡。傳送端會自動挑出位址（有 Tailscale 位址就優先用它），口令也會自動填好。
   - 如果跳出「允許尋找區域網路上的裝置」，點**允許**。
3. 確認系統聽寫已經打開：系統設定 → 鍵盤 → 聽寫。
4. 主視窗頂部顯示「已連上接收端」就可以用了。以後要改位址或口令，點主視窗裡「接收端」那一欄的「更改…」，或按 ⌘,。

## 怎麼用

1. 先在遠端桌面裡，點一下工作電腦上的輸入框，例如 Claude Code。
2. 按 **⌃⌥空白鍵（Ctrl + Option + 空白鍵）**，螢幕下方會跳出小視窗，並自動開始聽寫。如果聽寫沒有自動開始，就按一下 Fn。
3. 說話，說完按 **Return**，文字就出現在另一台電腦上。

| 按鍵 | 作用 |
|---|---|
| Return / 再按一次 ⌃⌥空白鍵 | 傳送 |
| Shift + Return | 換行 |
| Esc | 取消 |

小視窗頂部會顯示文字要傳到哪台電腦。左下角有一個「傳送後自動按 Enter」，預設是勾選的，文字會直接提交給 Claude。如果想先看一眼再手動提交，就取消勾選（主視窗的「選項」裡也有同一個開關）。

如果遠端軟體吃掉了這組按鍵，小視窗跳不出來，可以點主視窗裡的「說話」大按鈕，或者選單列圖示 →「說話」。

> **快速鍵可以改**：在「設定… → 快速鍵」裡點按鈕，再按下新的組合鍵。⌃⌥空白鍵 在有些 Mac 上已經被系統的「選擇輸入方式選單中的下一個輸入方式」佔用，按下去會切換輸入法。遇到這種情況，App 會顯示橘色提示：到 系統設定 → 鍵盤 → 鍵盤快速鍵 → 輸入方式 裡關掉那一項，或者在傳聲筒裡換一組按鍵。

## 兩種傳輸模式

在主視窗「傳輸方式」裡點「傳文字」或「傳聲音」那張卡片切換，選單列圖示的選單裡也能切。**預設是傳文字。**

| | 傳文字（預設） | 傳聲音 |
|---|---|---|
| 在哪裡辨識 | 在本機用系統聽寫辨識成文字 | 在對方電腦上辨識，用它自己的聽寫或 Claude Code 語音模式 |
| ⌃⌥空白鍵 的作用 | 跳出聽寫小視窗 | 開始或停止「一直傳」 |
| 按住 ⌃⌥ | — | 按住才傳，放開就停 |
| 主視窗的大按鈕 | 「說話」 | 「開始傳聲音」/「停止傳聲音」 |
| 對方需要 | 只要裝接收端 | 接收端，再加內建的虛擬音效卡 |

## 傳聲音模式

想讓工作的電腦**直接聽到你的聲音**時用這個模式，例如用那台電腦上 Claude Code 的語音模式，或者它自己的聽寫功能。

```
MacBook 麥克風 ──聲音──► 接收端 ──► 虛擬音效卡 MicHop Audio ──► 本機任何「聽麥克風」的程式
```

**接收端電腦上要先準備：**

1. 安裝內建的虛擬音效卡 **MicHop Audio**：第一次從傳送端傳聲音時，接收端會跳出提示，點「安裝」；也可以在接收端「設定… → 虛擬音效卡」裡點「安裝」。系統會要求輸入一次管理員密碼，裝完後系統聲音會中斷一兩秒。
2. 裝好後依照提示把**系統輸入裝置**改成 MicHop Audio（主視窗「準備狀況」裡也有「改過來」按鈕）。
3. 系統的**輸出**裝置保持揚聲器（或遠端軟體的聲音裝置）。MicHop Audio 本身就不能被選成系統輸出，不會把系統聲音混進來。

> **以前裝過 BlackHole？** 照常能用：在「準備狀況 → 聲音播到」裡選你想用的音效卡。想換成內建的，點「可以改用內建的虛擬音效卡」旁邊的「安裝」。用 BlackHole 時注意別把它選成系統輸出，選錯了「準備狀況」裡會出現「系統輸出」的警告，點「改回揚聲器」就行。

> **為什麼會有回音？** 很多遠端軟體（例如悠悠遠程）用 Apple 的螢幕錄製框架擷取被控端的聲音，會把那台電腦上**所有程式發出的聲音**都錄下來，不管它播到哪個音效卡。傳聲筒把你的聲音播進虛擬音效卡時，也會被一起錄走、傳回你的電腦，從揚聲器播出來，再被麥克風收進去。
>
> 所以傳送端預設開啟了**回音消除**（主視窗「選項」裡可以關）。它用的是 Apple 的語音處理，FaceTime 用的也是這一套：把傳回來的聲音從麥克風裡減掉；你說話時把其他聲音壓低；順便降噪。戴耳機效果最好。

**用法：**

在主視窗「傳輸方式」裡選「傳聲音」，傳送端就會連上接收端（第一次會請求麥克風權限），「連線狀態」變藍、選單列圖像變綠。之後有兩種說話方式，隨時都能用：

1. **一直傳**：按一下 **⌃⌥空白鍵**（或點「開始傳聲音」），麥克風一直開著；再按一下停止。
2. **按住傳**：**按住 Ctrl + Option 說話，放開就停**。只有按住的時候才打開麥克風，主視窗的「傳聲音」變紅，選單列圖像也變紅；放開後麥克風關閉，本機音量也不會被壓低。第一次會請求輔助使用權限，用來偵測這組按鍵；沒開的話，主視窗「選項」裡會提示，點「去開啟」。
3. 按住的這組按鍵還會被遠端軟體傳到工作的電腦上。如果你在那台電腦上把聽寫或輸入法的語音快捷鍵也設成 Ctrl + Option（見[下面的小技巧](#小技巧遠端連線時fn-鍵傳不過去換個快捷鍵)），**按一次就能同時完成「傳聲音」和「讓那邊開始聽寫」**。
4. 兩組快速鍵都能在「設定… → 快速鍵」裡改。

> 按住說話時，傳聲筒會把本機暫時靜音，免得對方電腦的聲音被遠端軟體傳回來、又被麥克風收進去形成回音；放開約 1 秒後自動恢復。（「一直傳」方式則使用 Apple 的回音消除。）

### 小技巧：遠端連線時，Fn 鍵傳不過去，換個快捷鍵

用悠悠遠程、向日葵、ToDesk 這類遠端軟體連線時，**在本機按 Fn 鍵，是傳不到被控端的**。不管被控端用的是系統聽寫，還是微信輸入法的語音輸入，都觸發不了。原因有兩個：Fn 鍵會先被本機攔下來（本機自己開始聽寫）；就算遠端軟體把它傳了過去，在被控端也只是「模擬按鍵」，系統和輸入法通常不認。

解決辦法：在**被控端**（例如 Mac mini）把語音輸入的快捷鍵換掉：

- **系統聽寫**：系統設定 → 鍵盤 → 聽寫 → 快速鍵 →「自訂」。
- **微信輸入法**：在微信輸入法的設定裡，修改語音輸入的快捷鍵。

推薦用**修飾鍵組合**，例如 **左側 Ctrl + Option**，或者 Ctrl 加其他修飾鍵（Option、Shift、Command）。

**不要用 Ctrl 加數字鍵或字母鍵**（例如 Ctrl+D）。語音輸入通常要按住說話，按住字母或數字鍵時，這個字元會被重複輸入，很不好用。純修飾鍵組合按住不會打出字元。

這一招搭配「傳聲音」模式使用：被控端的輸入裝置設成 MicHop Audio，在遠端桌面裡按住新快捷鍵說話，被控端就能直接聽寫了。

## 不在同一個網路？用 Tailscale

1. 兩台電腦都裝上 [Tailscale](https://tailscale.com)，登入同一個帳號。
2. 接收端主視窗「連線資訊」裡的「Tailscale」那一行會顯示 100.x.x.x，把它填到傳送端的設定裡。也可以填 Tailscale 裡顯示的機器名稱。
3. 如果顯示「未偵測到」，先確認接收端電腦上的 Tailscale 已連線，再點那一行的重新整理按鈕重新偵測。實在偵測不到，就在接收端「設定… → Tailscale → 手動填寫位址」裡，把 Tailscale 選單裡顯示的位址填進去。

Tailscale 位址在家和在外都能用，在同一個區域網路裡時，它會自動直連。

## 安全

- 每台接收端都有一個隨機的 6 位數口令，口令不對的請求一律拒絕。可以在接收端主視窗「口令」那一行點「換一個」（換完後傳送端要重新填）。
- 接收端監聽 TCP **8765**（文字）和 **8766**（聲音）兩個連接埠，傳輸不加密。建議只在家庭區域網路或 Tailscale 裡使用，不要把這些連接埠暴露到公網。
- 貼上時會暫時借用剪貼簿，大約 1 秒後恢復原來的內容。

## 常見問題

- **連不上**：確認兩台電腦在同一個網路，或者都已連上 Tailscale。區域網路 IP 可能會變，建議在路由器裡給接收端設一個固定 IP，或者直接用 Tailscale 位址。
- **提示沒開輔助使用權限**：重新編譯或更新 App 後，macOS 會讓原來的授權失效。在輔助使用列表裡先刪掉舊的那一項，再重新加入。

## 自動更新

兩個 App 都會自己去 GitHub 檢查新版本：啟動 30 秒後查一次，之後每 6 小時查一次。發現新版本，就自動下載、替換、重新打開。

- 主視窗左下角能看到目前版本號；在「設定… → 一般」裡可以點「檢查更新」立刻檢查。
- 不想自動安裝，就在「設定… → 一般」裡關掉「自動安裝更新」。之後有新版本時，設定裡會出現「更新到 x.y.z」按鈕，選單列選單裡也會出現同樣一項，點一下才更新。
- 不會在使用時打斷你：傳送端在聽寫小視窗開著時不更新；接收端在傳聲音時、或者 1 分鐘內剛收到過文字時，也不更新。
- 安全：新版本必須和目前版本用**同一張憑證**簽署，否則拒絕安裝。
