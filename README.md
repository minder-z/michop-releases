## 这是干什么的

我平时用 MacBook 办公，再用远程软件（悠悠远程、向日葵、ToDesk 等）连到 Mac mini 上干活，比如让 Claude Code 写代码、剪视频、维护网站。

麻烦的是：**Mac mini 没有麦克风，远程软件也不会把 MacBook 的麦克风传过去**，所以在远程桌面里没法语音输入。

传声筒解决的就是这个问题。两台电脑各装一个：

- **说话的电脑**（比如 MacBook）：装「传声筒」
- **干活的电脑**（比如 Mac mini）：装「传声筒接收端」

### 两种传法，主窗口里随时切换

```
MacBook（说话）                              Mac mini（干活）

麦克风 ──── 🔊 传声音 ────────────►  虚拟麦克风（自带的 MicHop Audio）
                                      → 系统听写 / 微信输入法 / Claude Code 语音模式

听写   ──── 📝 传文字 ────────────►  粘贴到光标所在的位置，可自动回车

              走局域网 或 Tailscale
```

**🔊 传声音：Mac mini 直接“听到”你说话**

MacBook 麦克风的声音实时传到 Mac mini，变成 Mac mini 的麦克风。Mac mini 上任何需要麦克风的程序都能用，比如系统听写、微信输入法的语音输入、Claude Code 的语音模式。

- 接收端自带虚拟声卡 **MicHop Audio**，第一次传声音时提示安装（要输入一次管理员密码），不用另外下载。以前装过 [BlackHole](https://github.com/ExistentialAudio/BlackHole) 的也能继续用。
- 自带回声消除，用远程软件连着也不会有回音。
- 远程软件里 Fn 键传不过去，记得把语音输入的快捷键换成功能键组合，比如 Ctrl + Option，[详见下文](#小技巧远程连接时fn-键传不过去换个快捷键)。

**📝 传文字：在 MacBook 上识别，把字发过去**

在 MacBook 上按 ⌃⌥空格（Ctrl + Option + 空格），用系统听写把话转成文字，再发到 Mac mini，自动粘贴到光标所在的位置，还可以自动回车，直接提交给 Claude。

- Mac mini 上不用装声卡，也不用设置音频，最省事、最稳定。
- App 默认就是这个模式。

| | 🔊 传声音 | 📝 传文字 |
|---|---|---|
| 在哪台电脑识别 | Mac mini（用它自己的听写或输入法） | MacBook（用系统听写） |
| Mac mini 需要准备 | 接收端 + 自带的虚拟声卡（第一次用时安装） | 只要接收端 |
| 适合 | 想用 Mac mini 上的输入法、听写、Claude 语音模式 | 只想把说的话变成字打进去 |

### 两台电脑怎么连

- **在同一个局域网里**：填 Mac mini 的局域网 IP 就行。
- **不在一起**：两台电脑都装 [Tailscale](https://tailscale.com) 组一个虚拟局域网，填 Mac mini 的 **Tailscale IP**（100 开头）。**声音和文字都能走 Tailscale 传**，在家在外都一样用。
- 接收端窗口里会列出局域网 IP、Tailscale IP 和口令，每一项旁边都有复制按钮。

### 其他特点

- **不经过任何云服务**：声音和文字只在你自己的两台电脑之间直传，走局域网，或者走 Tailscale 的加密通道。
- **和远程软件无关**：悠悠远程、向日葵、ToDesk、屏幕共享都能配合使用。
- **自动更新**：有新版本时会自己升级，权限不用重新授权。
- **多语言**：界面支持简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский，默认中文，在「设置… → 通用 → 语言 / Language」里切换。

## 下载安装

到 [Releases](../../releases/latest) 下载：

| 文件 | 装在哪台电脑 | 菜单栏图标 |
|---|---|---|
| `MicHop.zip`（传声筒） | 说话的电脑，比如 MacBook | 和 App 图标一样的圆角方块 |
| `MicHop-Receiver.zip`（传声筒接收端） | 干活的电脑，比如 Mac mini | 同上 |

菜单栏图标的颜色表示状态：**灰色**＝没连上，**绿色**＝连上了，**红色**＝正在传（说话 / 收声音）。

> **两个 App 都以主窗口为中心**：点程序坞图标就会弹出主窗口，顶部分两块显示状态：「连接状态」（灰 / 蓝）和「传声音」（灰 / 红），常用操作都在窗口里；语言、自动更新等放在「设置…」（⌘,）里。菜单栏图标和右键程序坞图标只保留最常用的几项。MacBook 的摄像头（刘海）挡住菜单栏图标时，用程序坞图标就行。

需要 macOS 13 或更高版本，Apple 芯片和 Intel 芯片都能用。

> **第一次打开提示“无法验证开发者”**：这是因为这个 App 没有花钱做苹果公证。打开 系统设置 → 隐私与安全性，在页面下方点「仍要打开」。也可以在终端里执行这条命令，解除隔离后再打开：
> ```bash
> xattr -dr com.apple.quarantine "/Applications/MicHop Receiver.app"
> ```

### 1. 干活的电脑（接收端）

1. 解压 `MicHop-Receiver.zip`，把「MicHop Receiver」拖进「应用程序」，然后打开。
2. 按提示打开**辅助功能**权限：系统设置 → 隐私与安全性 → 辅助功能 → 打开「传声筒接收端」。它需要这个权限才能替你按 ⌘V。
   - 如果弹出“是否允许接受传入的网络连接”，点**允许**。
3. 点程序坞里的「传声筒接收端」图标，主窗口里能看到：
   - **连接信息**：本机局域网地址、Tailscale 地址和口令，每一项旁边都有复制按钮。
   - **准备情况**：「辅助功能权限」那一行应该是绿色对勾。有黄色警告的项，右边会直接给出修复按钮。
4. 默认开机自动启动，不需要的话可以在「设置… → 通用」里关掉。

### 2. 说话的电脑（发送端）

1. 解压 `MicHop.zip`，把「MicHop」拖进「应用程序」，然后打开。
2. 第一次打开会弹出设置窗口：填上接收端的**地址**和**口令**，点「测试连接」，看到绿色的「连上了，可以用了」后点「保存」。
   - 在接收端窗口里，地址和口令旁边的复制按钮可以单独复制每一项。
   - 也可以在接收端点「复制全部」，然后把整段粘到「地址」框里。发送端会自动挑出地址（有 Tailscale 地址就优先用它），口令也会自动填好。
   - 如果弹出“允许查找本地网络上的设备”，点**允许**。
3. 确认系统听写已经打开：系统设置 → 键盘 → 听写。
4. 主窗口顶部显示「已连上接收端」就可以用了。以后要改地址或口令，点主窗口里「接收端」那一栏的「更改…」，或按 ⌘,。

## 怎么用

1. 先在远程桌面里，点一下干活电脑上的输入框，比如 Claude Code。
2. 按 **⌃⌥空格（Ctrl + Option + 空格）**，屏幕下方会弹出小窗，并自动开始听写。如果听写没有自动开始，就按一下 Fn。
3. 说话，说完按**回车**，文字就出现在另一台电脑上。

| 按键 | 作用 |
|---|---|
| 回车 / 再按一次 ⌃⌥空格 | 发送 |
| Shift + 回车 | 换行 |
| Esc | 取消 |

小窗顶部会显示文字要发到哪台电脑。左下角有一个「发送后自动回车」，默认是勾上的，文字会直接提交给 Claude。如果想先看一眼再手动提交，就取消勾选（主窗口的「选项」里也有同一个开关）。

如果远程软件吃掉了这组键，小窗弹不出来，可以点主窗口里的「说话」大按钮，或者菜单栏图标 →「说话」。

> **快捷键可以改**：「设置… → 快捷键」里点按钮，再按下新的组合键。⌃⌥空格 在有些 Mac 上已经被系统的「选择输入法菜单中的下一个输入法」占用，按下去会切换输入法。遇到这种情况，App 会显示橙色提示：到 系统设置 → 键盘 → 键盘快捷键 → 输入法 里关掉那一项，或者在传声筒里换一组键。

## 两种传输模式

在主窗口「传输方式」里点「传文字」或「传声音」那张卡片切换，菜单栏图标的菜单里也能切。**默认是传文字。**

| | 传文字（默认） | 传声音 |
|---|---|---|
| 在哪里识别 | 在本机用系统听写识别成文字 | 在对方电脑上识别，用它自己的听写或 Claude Code 语音模式 |
| ⌃⌥空格 的作用 | 弹出听写小窗 | 开始或停止「一直传」 |
| 按住 ⌃⌥ | — | 按住才传，松开就停 |
| 主窗口的大按钮 | 「说话」 | 「开始传声音」/「停止传声音」 |
| 对方需要 | 只要装接收端 | 接收端，再加自带的虚拟声卡 |

## 传声音模式

想让干活的电脑**直接听到你的声音**时用这个模式，比如用那台电脑上 Claude Code 的语音模式，或者它自己的听写功能。

```
MacBook 麦克风 ──声音──► 接收端 ──► 虚拟声卡 MicHop Audio ──► 本机任何“听麦克风”的程序
```

**接收端电脑上要先准备：**

1. 安装自带的虚拟声卡 **MicHop Audio**：第一次从发送端传声音时，接收端会弹出提示，点「安装」；也可以在接收端「设置… → 虚拟声卡」里点「安装」。系统会要求输入一次管理员密码，装完系统声音会中断一两秒。
2. 装好后按提示把**系统输入设备**改成 MicHop Audio（主窗口「准备情况」里也有「改过来」按钮）。
3. 系统的**输出**设备保持扬声器（或远程软件的声音设备）。MicHop Audio 本身就不能被选成系统输出，不会把系统声音混进来。

> **以前装过 BlackHole？** 照常能用：在「准备情况 → 声音播到」里选你想用的声卡。想换成自带的，点「可以改用自带的虚拟声卡」旁边的「安装」。用 BlackHole 时注意别把它选成系统输出，选错了「准备情况」里会出现「系统输出」的警告，点「改回扬声器」就行。

> **为什么会有回音？** 很多远程软件（比如悠悠远程）用苹果的屏幕录制框架采集被控端的声音，会把那台电脑上**所有程序发出的声音**都录下来，不管它播到哪个声卡。传声筒把你的声音播进虚拟声卡时，也会被一起录走、传回你的电脑，从扬声器放出来，再被麦克风收进去。
>
> 所以发送端默认开启了**回声消除**（主窗口「选项」里可以关）。它用的是苹果的语音处理，FaceTime 用的也是这一套：把传回来的声音从麦克风里减掉；你说话时把其他声音压低；顺便降噪。戴耳机效果最好。

**用法：**

在主窗口「传输方式」里选「传声音」，发送端就会连上接收端（第一次会请求麦克风权限），「连接状态」变蓝、菜单栏图标变绿。之后有两种说话方式，随时都能用：

1. **一直传**：按一下 **⌃⌥空格**（或点「开始传声音」），麦克风一直开着；再按一下停止。
2. **按住传**：**按住 Ctrl + Option 说话，松开就停**。只有按住的时候才打开麦克风，主窗口的「传声音」变红，菜单栏图标也变红；松开后麦克风关闭，本机音量也不会被压低。第一次会请求辅助功能权限，用来检测这组按键；没开的话，主窗口「选项」里会提示，点「去开启」。
3. 按住的这组键还会被远程软件传到干活的电脑上。如果你在那台电脑上把听写或输入法的语音快捷键也设成 Ctrl + Option（见[下面的小技巧](#小技巧远程连接时fn-键传不过去换个快捷键)），**按一次就能同时完成“传声音”和“让那边开始听写”**。
4. 两组快捷键都能在「设置… → 快捷键」里改。

> 按住说话时，传声筒会把本机暂时静音，免得对方电脑的声音被远程软件传回来、又被麦克风收进去形成回音；松开约 1 秒后自动恢复。（「一直传」方式则使用苹果的回声消除。）

### 小技巧：远程连接时，Fn 键传不过去，换个快捷键

用悠悠远程、向日葵、ToDesk 这类远程软件连接时，**在本机按 Fn 键，是传不到被控端的**。不管被控端用的是系统听写，还是微信输入法的语音输入，都触发不了。原因有两个：Fn 键会先被本机拦下来（本机自己开始听写）；就算远程软件把它传了过去，在被控端也只是“模拟按键”，系统和输入法通常不认。

解决办法：在**被控端**（比如 Mac mini）把语音输入的快捷键换掉：

- **系统听写**：系统设置 → 键盘 → 听写 → 快捷键 →「自定」。
- **微信输入法**：在微信输入法的设置里，修改语音输入的快捷键。

推荐用**功能键组合**，比如 **左侧 Ctrl + Option**，或者 Ctrl 加其他功能键（Option、Shift、Command）。

**不要用 Ctrl 加数字键或字母键**（比如 Ctrl+D）。语音输入通常要按住说话，按住字母或数字键时，这个字符会被反复输入，很不好用。纯功能键组合按住不会打出字符。

这一招配合「传声音」模式使用：被控端的输入设备设成 MicHop Audio，在远程桌面里按住新快捷键说话，被控端就能直接听写了。

## 不在同一个网络？用 Tailscale

1. 两台电脑都装上 [Tailscale](https://tailscale.com)，登录同一个账号。
2. 接收端主窗口「连接信息」里的「Tailscale」那一行会显示 100.x.x.x，把它填到发送端的设置里。也可以填 Tailscale 里显示的机器名。
3. 如果显示“未检测到”，先确认接收端电脑上的 Tailscale 已连接，再点那一行的刷新按钮重新检测。实在检测不到，就在接收端「设置… → Tailscale → 手动填写地址」里，把 Tailscale 菜单里显示的地址填进去。

Tailscale 地址在家和在外都能用，在同一个局域网里时，它会自动直连。

## 安全

- 每台接收端都有一个随机的 6 位口令，口令不对的请求一律拒绝。可以在接收端主窗口「口令」那一行点「换一个」（换完后发送端要重新填）。
- 接收端监听 TCP **8765**（文字）和 **8766**（声音）两个端口，传输不加密。建议只在家庭局域网或 Tailscale 里使用，不要把这个端口暴露到公网。
- 粘贴时会临时借用剪贴板，大约 1 秒后恢复原来的内容。

## 常见问题

- **连不上**：确认两台电脑在同一个网络，或者都已连上 Tailscale。局域网 IP 可能会变，建议在路由器里给接收端设一个固定 IP，或者直接用 Tailscale 地址。
- **提示没开辅助功能权限**：重新编译或更新 App 后，macOS 会让原来的授权失效。在辅助功能列表里先删掉旧的那一项，再重新添加。

## 自动更新

两个 App 都会自己去 GitHub 检查新版本：启动 30 秒后查一次，之后每 6 小时查一次。发现新版本，就自动下载、替换、重新打开。

- 主窗口左下角能看到当前版本号；在「设置… → 通用」里可以点「检查更新」立刻检查。
- 不想自动安装，就在「设置… → 通用」里关掉「自动安装更新」。之后有新版本时，设置里会出现「更新到 x.y.z」按钮，菜单栏菜单里也会出现同样一项，点一下才更新。
- 不会在用的时候打断你：发送端在听写小窗开着时不更新；接收端在传声音时、或者 1 分钟内刚收到过文字时，也不更新。
- 安全：新版本必须和当前版本用**同一张证书**签名，否则拒绝安装。
- 升级后，辅助功能、麦克风等权限会保留，不用重新授权。
