## 安装 · Install

1. 解压，把 App 拖进「应用程序」，然后打开。· Unzip, drag the app into Applications, and open it.
2. 第一次打开如果提示“无法验证开发者”：打开 系统设置 → 隐私与安全性，在页面下方点「仍要打开」。· If macOS says the developer can't be verified, open System Settings → Privacy & Security and click “Open Anyway”.
3. 之后有新版本时，App 会自己更新。· After that, the apps update themselves.
